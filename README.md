# Platformer Adventure

Bienvenue dans *Platformer Adventure*, un jeu de plateforme 2D développé en Python avec la bibliothèque [Arcade]

> Ce projet est le fruit d’un travail modulaire et structuré, avec des mécaniques de jeu complètes : plateformes mobiles, leviers, portes, monstres, objets à collecter, armes multiples... et bien sûr, des pièges en lave pour les plus distraits 

---

## Objectif du jeu

Vous incarnez un personnage qui doit atteindre la sortie de chaque niveau (le panneau "E") en évitant les ennemis, la lave et en collectant des objets utiles.

- Utilisez les **leviers** pour ouvrir ou fermer des **portes**
- Évitez les **blobs**, les **chauves-souris** et les **fantômes**
- Ramassez des **pommes** pour devenir temporairement invincible 
- Utilisez votre **épée** ou **arc/flèches** pour combattre
- Et surtout... **survivez** 

---

## Contrôles

| Action              | Touche / Souris         |
|---------------------|--------------------------|
| Aller à droite      | `→`                      |
| Aller à gauche      |  `←`                     |
| Sauter              | `↑`                      |
| Changer d’arme      | Clic droit               |
| Attaquer            | Clic gauche              |
| Relancer la partie  | `ESPACE` après Game Over |
